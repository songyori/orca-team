# 00 — 무엇을 만드나

orca-team 에 내장한 Codex 래퍼(`orca-team/scripts/codex-run.sh`)와 이미지 생성(`/orca-team:image`)의 요구와 결정이다. 회귀 테스트는 `orca-team/tests/test-codex-run.sh`, 점검은 `orch doctor` 다. orca-team 에는 `run` 스킬이 없다. 본문의 `run` 스킬 이야기는 설계 당시 기록이다(래퍼의 `run` 프로파일은 `orch review` 가 쓴다).

## 요구사항 (2026-09-06)

1. codex 를 cli 로 호출해서 업무를 맡긴다. 정상적인 codex cli 호출을 보장할 수 있어야 한다.
   우회 모드로 모든 파일에 접근·작성이 가능해야 한다. 명시적 명령어를 통한 호출과
   프롬프트 입력(코덱스 요청 프롬프트)을 모두 지원한다.
2. codex cli 로 이미지를 생성한다. gpt-image-2 를 통한 이미지 생성을 지원한다. 이 역시 명시적
   명령어와 프롬프트 입력(이미지 생성과 관련한 프롬프트)을 모두 지원한다.

| 요구 | 뜻 | 정본 |
