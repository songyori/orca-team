# orca-team 플러그인 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/orca-team:init <프로젝트 설명>` 한 번으로 메인/코디네이터/직무 워커 3계층 Orca 오케스트레이션과 Codex 리뷰를 세팅하고, 이후 동작을 결정적 CLI(`orch`)로 고정하는 Claude Code 플러그인을 만든다.

**Architecture:** 플러그인 `orca-team`은 결정적 CLI(`bin/orch`, Python 패키지 `lib/orch`)와 훅(`hooks/orca_team_hook.py`), 템플릿, 스킬 두 개(`init`, `up`)로 이뤄진다. 배치·모델·리뷰 규칙은 `orch`와 프로젝트 `config.toml`에만 있고, 에이전트는 `orch`만 호출한다. 메인 세션은 Orca Run에 묶이지 않는다. 코디네이터(별도 Orca 터미널)가 Run을 소유하고, 코디네이터→메인 메시지는 `outbox.jsonl` 파일과 메인의 백그라운드 `orch watch`로 흐른다.

**Tech Stack:** Python 3.11+ 표준 라이브러리(`tomllib`, `argparse`, `unittest`), bash(Codex 래퍼), Orca CLI 1.4.x, Codex CLI 0.16x, Claude Code 플러그인(skills, hooks).

**설계 문서:** `docs/superpowers/specs/2026-10-30-orca-team-design.md`

## Global Constraints

- Python 3.11 이상, 표준 라이브러리만 사용한다. 외부 패키지를 설치하지 않는다.
- 모든 Orca 호출은 `lib/orch/orca.py`의 `call()`을 거치고 `--json`을 붙인다.
- 워커 배치는 항상 `orca orchestration worker-start --worktree current --agent claude --model <M> --effort <E>`다. 워커 터미널 재사용 때만 `--terminal <handle>`을 쓴다(이때 `--agent/--model/--effort` 없음).
- 코디네이터 기동은 항상 `orca agent launch --agent claude --surface terminal --worktree path:<root> --model <M> --effort <E> --prompt "[orca-team:coordinator] ..."`다.
- Codex 호출은 항상 Codex 래퍼 `codex-run.sh --profile run ... --bypass-hook-trust`다.
- 종료 코드: 0 성공, 1 실패, 2 인자·상태 오류, 3 중복 실행, 12 의존성 없음.
- 모델 기본값(설계 §4.3): 코디네이터 opus/xhigh, planner opus/xhigh + gpt-6.1-sol/high, designer sonnet/xhigh + gpt-6.1-sol/medium, developer opus/xhigh + gpt-6-astra/xhigh, tester sonnet/xhigh + gpt-6.1-sol/high.
- 메인은 Run에 바인딩되지 않는다. `bind`, `wait`, `task new`, `start`, `fix`, `review`, `accept`는 `ORCA_TERMINAL_HANDLE`이 `run.json`의 `coordinator_handle`과 같을 때만 실행한다.
- 디자인 도구 규칙: 앱·웹 화면 디자인은 Claude Design(Artifact Design 타입), 래스터 에셋만 `/orca-team:image`(Codex), SVG·CSS·다이어그램은 코드.
- 문서·주석·사용자 메시지는 한국어로 쓴다. 식별자와 명령은 원문 그대로 둔다.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`를 붙인다.

## 설계 대비 조정

구현 중 다음을 설계에서 바꾼다. Task 11에서 설계 문서 §13에 기록한다.

1. 훅은 셸 스크립트 4개 대신 Python 파일 하나(`hooks/orca_team_hook.py <event>`)로 만든다. `jq` 의존이 없고, `orch`와 같은 경로 해석 코드를 쓴다.
2. `orch wait`는 60분 대기(`--timeout-ms 3600000`)이고 Bash `run_in_background`로 띄운다. Bash 포그라운드 상한이 10분이라 15분 포그라운드 대기는 불가능하다. 중복 실행은 `wait.pid`로 막는다.
3. `orch bind`(코디네이터가 Run 생성·재연결)와 `orch which`(Orca task/dispatch ID → T-xxx)를 추가한다.
4. 프로젝트 `.orchestration/bin/orch` shim을 항상 쓴다. 플러그인 `bin/`의 PATH 등록 여부와 상관없이 모든 역할이 같은 경로를 쓴다(설계 §11-5 해소).
5. 리포트 템플릿 파일은 따로 두지 않는다. 리포트 형식은 워커 spec(`templates/worker-spec.md`)에 들어 있다.
6. 리뷰 중 Codex 파일 변경 검사는 다른 진행 태스크의 소유 경로, `.orchestration/**`, `docs/reviews/**`를 뺀 작업 트리 내용 해시로 한다. 단일 체크아웃에서 다른 워커와 코디네이터가 동시에 쓰는 경로를 오탐하지 않기 위해서다.

```python
#!/usr/bin/env python3
"""가짜 orca. argv 를 $FAKE_DIR/orca.log 에 JSON 한 줄로 남기고 등록된 응답을 돌려준다.

응답 파일: $FAKE_DIR/<플래그가 아닌 앞 두 토큰을 _ 로 이은 이름>.json = {"code": int, "body": {...}}
예: orchestration worker-start → orchestration_worker-start.json, status → status.json
없으면 {"ok": true, "result": {}} 를 출력하고 exit 0.
"""
import json
import os
import sys
from pathlib import Path

fake = Path(os.environ["FAKE_DIR"])
args = sys.argv[1:]
with (fake / "orca.log").open("a", encoding="utf-8") as fh:
    fh.write(json.dumps(args, ensure_ascii=False) + "\n")
words = [a for a in args if not a.startswith("--")][:2]
response = fake / ("_".join(words) + ".json")
if response.exists():
    spec = json.loads(response.read_text(encoding="utf-8"))
    print(json.dumps(spec["body"], ensure_ascii=False))
    sys.exit(spec.get("code", 0))
print(json.dumps({"ok": True, "result": {}}))
sys.exit(0)
```

```python
#!/usr/bin/env python3
"""가짜 codex-run.sh(Codex 래퍼). --bypass-hook-trust 를 받는다.

argv 를 $FAKE_DIR/codex-run.log 에 남기고 $FAKE_DIR/codex_run_modes.txt 의 첫 단어(없으면 approve)대로 행동한다.
모드: approve | changes | noverdict | fail | modify | touch_other
리뷰 파일 경로는 프롬프트의 `REVIEW_FILE: <경로>` 줄에서 읽는다.
"""
import json
import os
import re
import sys
from pathlib import Path

fake = Path(os.environ["FAKE_DIR"])
args = sys.argv[1:]
with (fake / "codex-run.log").open("a", encoding="utf-8") as fh:
    fh.write(json.dumps(args, ensure_ascii=False) + "\n")


def opt(name):
    return args[args.index(name) + 1]


modes_file = fake / "codex_run_modes.txt"
modes = modes_file.read_text(encoding="utf-8").split() if modes_file.exists() else []
mode = modes.pop(0) if modes else "approve"
modes_file.write_text("".join(m + "\n" for m in modes), encoding="utf-8")

cwd, run_dir = Path(opt("--cwd")), Path(opt("--run-dir"))
prompt = Path(opt("--prompt-file")).read_text(encoding="utf-8")
review = cwd / re.search(r"^REVIEW_FILE: (\S+)$", prompt, re.M).group(1)
status = {"exit": 0, "terminal_event": "turn.completed"}
if mode == "fail":
    status = {"exit": 11, "terminal_event": None}
else:
    verdict = {"approve": "APPROVE", "changes": "REQUEST_CHANGES", "modify": "APPROVE",
               "touch_other": "APPROVE"}.get(mode)
    review.parent.mkdir(parents=True, exist_ok=True)
    review.write_text("# 리뷰\n\n없음\n" + (f"\nVERDICT: {verdict}\n" if verdict else ""), encoding="utf-8")
    if mode == "modify":
        (cwd / "src").mkdir(exist_ok=True)
        (cwd / "src" / "codex-touched.txt").write_text("x\n", encoding="utf-8")
    if mode == "touch_other":
        (cwd / "tests").mkdir(exist_ok=True)
        (cwd / "tests" / "concurrent.txt").write_text("x\n", encoding="utf-8")
(run_dir / "status.json").write_text(json.dumps(status), encoding="utf-8")
sys.exit(status["exit"])
```

```python
"""테스트 공용: 임시 git 프로젝트와 가짜 orca/codex/Codex 래퍼 환경."""
from __future__ import annotations

import json
import os
import shutil
import subprocess
import sys
import tempfile
import unittest
from pathlib import Path

PLUGIN = Path(__file__).resolve().parents[1]
FAKES = PLUGIN / "tests" / "fakes"
ORCH = PLUGIN / "bin" / "orch"
sys.path.insert(0, str(PLUGIN / "lib"))


class ProjectCase(unittest.TestCase):
    """임시 git 프로젝트. 기본 환경은 코디네이터 터미널(ORCA_TERMINAL_HANDLE=term_coord)이다."""

    def setUp(self):
        self.tmp = Path(tempfile.mkdtemp(prefix="orca-team-test-")).resolve()
        self.root = self.tmp / "proj"
        self.root.mkdir()
        self.fake_dir = self.tmp / "fake"
        self.fake_dir.mkdir()
        self.env = {
            **os.environ,
            "ORCA_TEAM_ORCA": str(FAKES / "orca"),
            "ORCA_TEAM_CODEX": str(FAKES / "codex"),
            "ORCA_TEAM_CODEX_RUN": str(FAKES / "codex-run.sh"),
            "ORCA_TEAM_PLUGINS_JSON": str(self.tmp / "installed_plugins.json"),
            "ORCA_TEAM_PLUGIN_ROOT": str(PLUGIN),
            "FAKE_DIR": str(self.fake_dir),
            "XDG_CACHE_HOME": str(self.tmp / "cache"),
            "ORCA_TERMINAL_HANDLE": "term_coord",
            "GIT_AUTHOR_NAME": "t", "GIT_AUTHOR_EMAIL": "t@example.com",
            "GIT_COMMITTER_NAME": "t", "GIT_COMMITTER_EMAIL": "t@example.com",
        }
        for key in ("ORCA_CLI_COMMAND", "CLAUDE_PROJECT_DIR"):
            self.env.pop(key, None)
        self.git("init", "-q", "-b", "main")
        self.git("commit", "-q", "--allow-empty", "-m", "init")

    def tearDown(self):
        shutil.rmtree(self.tmp, ignore_errors=True)

    def git(self, *args: str) -> str:
        return subprocess.run(["git", *args], cwd=self.root, env=self.env,
                              capture_output=True, text=True, check=True).stdout

    def orch(self, *args: str, check: bool = True, env: dict | None = None) -> subprocess.CompletedProcess:
        proc = subprocess.run([sys.executable, str(ORCH), *args], cwd=self.root,
                              env={**self.env, **(env or {})}, capture_output=True, text=True)
        if check and proc.returncode != 0:
            self.fail(f"orch {' '.join(args)} exit {proc.returncode}\nstdout:\n{proc.stdout}\nstderr:\n{proc.stderr}")
        return proc

    def respond(self, key: str, body: dict, code: int = 0) -> None:
        """가짜 orca 응답 등록. key 예: 'orchestration worker-start', 'status'."""
        path = self.fake_dir / (key.replace(" ", "_") + ".json")
        path.write_text(json.dumps({"code": code, "body": body}), encoding="utf-8")

    def calls(self) -> list[list[str]]:
        log = self.fake_dir / "orca.log"
        if not log.exists():
            return []
        return [json.loads(line) for line in log.read_text(encoding="utf-8").splitlines()]

    def calls_for(self, key: str) -> list[list[str]]:
        parts = key.split()
        return [c for c in self.calls() if c[:len(parts)] == parts]

    def scaffold(self) -> None:
        """orch scaffold 후 코디네이터가 Run 을 만든 상태로 둔다."""
        desc = self.tmp / "desc.txt"
        desc.write_text("테스트 프로젝트. 할 일 웹앱.", encoding="utf-8")
        self.orch("scaffold", "--description-file", str(desc))
        (self.root / ".orchestration/state/run.json").write_text(
            json.dumps({"run_id": "run_x", "coordinator_handle": "term_coord"}), encoding="utf-8")
```

```python
"""orca-team CLI 진입점."""
import sys
from pathlib import Path

if sys.version_info < (3, 11):
```

```python
def write_json(path: Path, data) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=path.parent, prefix=f".{path.name}.", suffix=".tmp")

    proc = subprocess.run(["git", "-C", str(root), *args], capture_output=True, text=True)
    if check and proc.returncode != 0:
        raise OrchError(f"git {' '.join(args)} 실패: {proc.stderr.strip()}")

def git_commit_paths(root: Path, paths: list[str], message: str) -> None:
    """지정 경로만 커밋한다. 다른 워커와 index.lock 이 겹치면 1초 쉬고 다시 한다(최대 6회)."""
    for attempt in range(6):
        add = subprocess.run(["git", "-C", str(root), "add", "--", *paths], capture_output=True, text=True)
        err = add.stderr
        if add.returncode == 0:
            commit = subprocess.run(["git", "-C", str(root), "commit", "-q", "-m", message, "--only", "--", *paths],
                                    capture_output=True, text=True)
            if commit.returncode == 0:
                return
            err = commit.stderr + commit.stdout
        if "index.lock" not in err or attempt == 5:
            raise OrchError(f"커밋 실패({', '.join(paths)}): {err.strip()}")
        time.sleep(1.0)
```

```python
"""소유 경로 glob. `**` 는 여러 단계, `*`·`?` 는 한 단계 안에서만 맞는다."""
from __future__ import annotations

import re
from functools import lru_cache

GLOB_CHARS = "*?["


@lru_cache(maxsize=512)
def _regex(pattern: str) -> re.Pattern:
    out, i = [], 0
    while i < len(pattern):
        if pattern.startswith("**/", i):
            out.append("(?:.*/)?")
            i += 3
        elif pattern.startswith("**", i):
            out.append(".*")
            i += 2
        elif pattern[i] == "*":
            out.append("[^/]*")
            i += 1
        elif pattern[i] == "?":
            out.append("[^/]")
            i += 1
        else:
            out.append(re.escape(pattern[i]))
            i += 1
    return re.compile("".join(out) + r"\Z")


def matches(path: str, pattern: str) -> bool:
    return bool(_regex(pattern).match(path))


def matches_any(path: str, patterns) -> bool:
    return any(matches(path, p) for p in patterns)


def literal_prefix(pattern: str) -> str:
    cut = min((pattern.index(c) for c in GLOB_CHARS if c in pattern), default=len(pattern))
    return pattern[:cut]


def overlaps(a: str, b: str) -> bool:
    """보수적 판정. 리터럴 접두가 서로의 접두면 겹친다고 본다."""
    pa, pb = literal_prefix(a), literal_prefix(b)
    if pa == a and pb == b:
        return a == b
    if pa == a:
        return matches(a, b)
    if pb == b:
        return matches(b, a)
    return pa.startswith(pb) or pb.startswith(pa)


def any_overlap(xs, ys) -> list[tuple[str, str]]:
    return [(x, y) for x in xs for y in ys if overlaps(x, y)]
```

```python
"""config.toml 해석: 직무, 소유 경로, 모델 우선순위(overrides > 직무 > defaults)."""
from __future__ import annotations

import tomllib
from dataclasses import dataclass
from pathlib import Path

from .paths import OrchError


@dataclass(frozen=True)
class Launch:
    model: str
    effort: str


class Config:
    def __init__(self, data: dict):
        self.data = data

    @classmethod
    def load(cls, path: Path) -> "Config":
        try:
            return cls(tomllib.loads(path.read_text(encoding="utf-8")))
        except (OSError, tomllib.TOMLDecodeError) as exc:
            raise OrchError(f"{path} 읽기 실패: {exc}", 2) from exc

    @property
    def roles(self) -> dict:
        return self.data.get("roles", {})

    def role(self, name: str) -> dict:
        if name not in self.roles:
            raise OrchError(f"알 수 없는 직무: {name}. 가능한 직무: {', '.join(sorted(self.roles))}", 2)
        return self.roles[name]

    def title(self, name: str) -> str:
        return str(self.role(name).get("title", name))

    def owns(self, name: str, override: list[str] | None = None) -> list[str]:
        owns = list(override or self.role(name).get("owns", []))
        if not owns:
            raise OrchError(f"{name}: owns 가 비어 있다(config.toml [roles.{name}].owns)", 2)
        return owns

    def claude(self, name: str, overrides: dict | None = None) -> Launch:
        return self._launch(name, "claude", overrides or {})

    def codex(self, name: str, overrides: dict | None = None) -> Launch:
        return self._launch(name, "codex", overrides or {})

    def _launch(self, name: str, kind: str, overrides: dict) -> Launch:
        role, defaults = self.role(name), self.data.get("defaults", {})
        values = []
        for field in ("model", "effort"):
            key = f"{kind}_{field}"
            value = overrides.get(key) or role.get(key) or defaults.get(key)
            if not value:
                raise OrchError(f"{name}: {key} 미설정(config.toml)", 2)
            values.append(str(value))
        return Launch(*values)

    def coordinator(self) -> Launch:
        section = self.data.get("coordinator", {})
        return Launch(str(section.get("model", "opus")), str(section.get("effort", "xhigh")))

    @property
    def max_rounds(self) -> int:
        return int(self.data.get("review", {}).get("max_rounds", 3))
```

````markdown
# 코디네이터 운영 절차

너는 orca-team 코디네이터다. 사용자와 직접 대화하지 않는다. 메인 에이전트가 사용자와 대화하고, 너는 메인이 넘긴 요청을 태스크로 나눠 직무 워커에게 맡기고 Codex 리뷰를 돌린다.

모든 명령은 `.orchestration/bin/orch`(아래 `orch`)로 한다. Orca 배치·모델 플래그를 직접 고르지 않는다.

## 금지
- 산출물(기획 문서, 디자인, 코드, 테스트) 작성·수정. 쓸 수 있는 곳은 `.orchestration/` 뿐이다(훅이 막는다).
- AskUserQuestion. 사용자 결정이 필요하면 `orch notify --type question`.
- `[main]` 메시지에 `orca orchestration reply`. 메인에게는 `orch notify` 로만 답한다(reply 는 메인 입력란을 깨운다).
- Claude 서브에이전트(Agent tool)·Workflow 로 작업 대신하기. 모든 작업은 `orch start` 로 Orca 워커에게 맡긴다.
- `orca orchestration worker-start` 직접 호출. 실패한 start·fix 를 `--retry` 없이 다시 실행하기.

## 시작
1. `orch bind` — Run 을 만들거나 기존 Run 에 다시 붙는다.
2. `orch status` — 진행 중 태스크를 본다. `working` 태스크는 워커의 worker_done 을 기다린다. `reviewing` 은 이전 코디네이터가 리뷰 도중 끊긴 것이다. `.orchestration/state/tasks/T-xxx.json` 의 status 를 `working` 으로 고친 뒤 `orch review T-xxx` 를 다시 돌린다.
3. `.orchestration/project.md`, `.orchestration/config.toml`, `.orchestration/roles/*.md` 를 읽는다.
4. `orch notify --type progress "코디네이터 준비 완료"`.
5. 대기 루프로 간다.

## 대기 루프
- `orch wait` 를 Bash `run_in_background: true` 로 띄운다. 한 번에 하나만 띄운다(중복이면 exit 3).
- 완료 알림이 오면 출력 JSON 의 `result.messages` 를 모두 처리한다. 그다음 `orch wait --ack <result.deliveryId>` 를 다시 백그라운드로 띄운다. 메시지가 없거나 타임아웃이면 `--ack` 없이 다시 띄운다.
- 워커 메시지가 어느 태스크인지는 `orch which <taskId 또는 dispatchId>` 로 찾는다.

| 메시지 | 처리 |
|---|---|
| subject `[main] reply out-NNNN` | 그 question 에 대한 사용자 답. 기다리던 일에 반영한다. 워커 ask 였으면 `orca orchestration reply --id <워커 메시지 id> --body "<답>"` |
| subject `[main] ...` | 사용자 요청. 아래 "요청 처리" |
| question (워커 ask) | spec·직무 정의·project.md 로 답할 수 있으면 `orca orchestration reply --id <id> --body "<답>"`. 사용자 결정이 필요하면 `orch notify --type question "<질문, 선택지, 추천>"` 하고, 답이 오면 reply 한다 |
| worker_done (outcome succeeded) | `orch review T-xxx` 를 Bash `run_in_background: true` 로 실행 |
| worker_done (outcome failed) | 리포트를 읽고 `orch fix T-xxx --note "<원인과 지시>"` 또는 `orch notify --type question` |
| escalation | 내용을 정리해 `orch notify --type question` |
| heartbeat, 그 외 status | 처리할 것 없음 |

리뷰 완료 알림이 오면 출력의 verdict 로 정한다.
- APPROVE → `orch accept T-xxx`. 이 태스크를 기다리던 태스크가 있으면 `orch start`.
- REQUEST_CHANGES → `orch fix T-xxx`(리뷰 파일을 읽고 필요하면 `--note`). 최대 라운드 초과로 거부되면 `orch notify --type question` 으로 리뷰 요약과 선택지를 올린다.
- exit≠0 → 출력의 지시를 따른다. 해결하지 못하면 `orch notify --type question`.

## 요청 처리
1. 요청을 태스크로 나눈다. 태스크 하나 = 직무 하나 = 검증 가능한 결과 하나. 현재 요청에 필요한 만큼만 만든다.
2. `orch task new <role> "<제목>"` → `.orchestration/tasks/T-xxx.md` 의 Target·Change·Constraints·Acceptance 를 채운다. `<...>` 자리표시가 남으면 start 가 거부한다. 소유 경로를 좁히려면 front matter 에 `owns: src/auth/**, src/ui/login/**` 를 넣는다.
3. spec 을 커밋한다: `git add .orchestration/tasks/T-xxx.md && git commit -m "[T-xxx] spec: <제목>"`.
4. 선행 관계가 없는 태스크는 함께 `orch start` 한다. 소유 경로가 겹치면 orch 가 거부한다. 앞 태스크를 accept 한 뒤 시작한다.
5. `orch notify --type progress "<태스크 목록: id, 직무, 제목>"`.
6. 요청의 모든 태스크가 done 이면 `orch notify --type done "<결과 요약, 바뀐 주요 파일, 태스크별 리뷰 판정>"`.
7. 진행 중 범위를 더하면 spec 파일에 "추가 범위"로 적고 `[T-xxx] spec:` 으로 커밋한다. 그다음 `orca orchestration send --to dispatch:<dispatchId> --subject "추가 범위" --body "<내용>"` 으로 워커에게 알린다.

## 직무 선택
- planner: 요구사항, 기능 명세, 사용자 흐름, 수용 기준
- designer: 앱·웹 화면 디자인(Claude Design), 디자인 시스템, 래스터 에셋(/orca-team:image)
- developer: 구현
- tester: 테스트 작성·실행, QA 리포트

## 디자인 산출물 규칙
- 앱·웹 화면 디자인은 designer 가 Claude Design(Artifact 도구의 Design 타입)으로 만든다.

- SVG·CSS·다이어그램은 코드로 만든다.
````

```python
"""orca-team shim. 설치된 orca-team 플러그인의 bin/orch 를 실행한다(플러그인 갱신이 바로 반영된다)."""
import json
import os
import sys
from pathlib import Path


def plugin_root():
    override = os.environ.get("ORCA_TEAM_PLUGIN_ROOT")
    if override:
        return Path(override)
    registry = Path(os.environ.get("ORCA_TEAM_PLUGINS_JSON")
                    or Path.home() / ".claude" / "plugins" / "installed_plugins.json")
    try:
        data = json.loads(registry.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError):
        return None
    for key, entries in data.get("plugins", data).items():
        if key.split("@", 1)[0] != "orca-team" or not isinstance(entries, list):
            continue
        for entry in sorted(entries, key=lambda e: e.get("scope") != "user"):
            path = entry.get("installPath")
            if path and Path(path, "bin", "orch").is_file():
                return Path(path)
    return None


root = plugin_root()
if root is None:
    sys.stderr.write("orca-team 플러그인이 설치돼 있지 않다: /plugin install orca-team@setup-with-orca\n")
    sys.exit(12)
os.execv(sys.executable, [sys.executable, str(root / "bin" / "orch"), *sys.argv[1:]])
```

```python
"""orca CLI 호출. 모든 호출은 --json 이다."""
from __future__ import annotations

import json
import subprocess

from .paths import OrchError, orca_bin


def last_json(text: str) -> dict | None:
    """여러 JSON 객체가 이어진 출력에서 `_keepalive` 가 아닌 마지막 객체."""
    decoder, index, last = json.JSONDecoder(), 0, None
    while index < len(text):
        while index < len(text) and text[index].isspace():
            index += 1
        if index >= len(text):
            break
        try:
            obj, index = decoder.raw_decode(text, index)
        except json.JSONDecodeError:
            return last
        if isinstance(obj, dict) and not obj.get("_keepalive"):
            last = obj
    return last


def call(args: list[str], check: bool = True) -> tuple[int, dict]:
    cmd = [orca_bin(), *args, "--json"]
    try:
        proc = subprocess.run(cmd, capture_output=True, text=True)
    except FileNotFoundError as exc:
        raise OrchError(f"orca 실행 파일 없음: {cmd[0]}", 12) from exc
    data = last_json(proc.stdout)
    label = " ".join(args[:2])
    if data is None:
        raise OrchError(f"orca {label} 출력 파싱 실패(exit {proc.returncode}): {(proc.stdout + proc.stderr)[-800:]}")
    if check and (proc.returncode != 0 or not data.get("ok", False)):
        raise OrchError(f"orca {label} 실패(exit {proc.returncode}): {json.dumps(data, ensure_ascii=False)[:1500]}")
    return proc.returncode, data


def find_key(node, names: tuple[str, ...]):
    """응답 JSON 에서 names 중 처음 맞는 키의 값을 깊이 우선으로 찾는다."""
    if isinstance(node, dict):
        for name in names:
            if isinstance(node.get(name), (str, int)):
                return node[name]
        for value in node.values():
            found = find_key(value, names)
            if found is not None:
                return found
    elif isinstance(node, list):
        for item in node:
            found = find_key(item, names)
            if found is not None:
                return found
    return None


def terminal_alive(handle: str | None) -> bool:
    """터미널이 연결돼 있고 그 안에서 claude 에이전트가 도는지."""
    if not handle:
        return False
    code, data = call(["terminal", "show", "--terminal", handle], check=False)
    term = (data.get("result") or {}).get("terminal") or {}
    return (code == 0 and bool(data.get("ok")) and term.get("connected") is True
            and not term.get("orphaned") and term.get("agentIdentity") == "claude")


def worker_terminal(dispatch_id: str) -> tuple[str | None, str | None]:
    """(에이전트 터미널 handle, liveness verdict). 조회 실패면 (None, None)."""
    code, data = call(["orchestration", "worker-show", "--dispatch", dispatch_id], check=False)
    if code != 0 or not data.get("ok"):
        return None, None
    result = data.get("result") or {}
    handle = (result.get("worker") or {}).get("agentTerminalHandle")
    verdict = ((result.get("projection") or {}).get("liveness") or {}).get("verdict")
    return handle, verdict
```

```python
def doctor(start: Path) -> list[Check]:
    checks = [Check("python>=3.11", sys.version_info >= (3, 11), sys.version.split()[0])]
    top = git_toplevel(start)
    checks.append(Check("git 저장소", top is not None, str(top) if top else "없음(init 이 git init 한다)", required=False))
    try:
        _, data = orca.call(["status"], check=False)
        state = ((data.get("result") or {}).get("runtime") or {}).get("state")
        checks.append(Check("orca runtime", state == "ready", f"runtime.state={state}"))
    except OrchError as exc:
        checks.append(Check("orca runtime", False, str(exc)))
    codex = shutil.which(codex_bin())
    if codex:
        proc = subprocess.run([codex, "login", "status"], capture_output=True, text=True)
        out = (proc.stdout + proc.stderr).strip()
        checks.append(Check("codex 로그인", "Logged in" in out, out.splitlines()[0] if out else f"exit {proc.returncode}"))
    else:
        checks.append(Check("codex 로그인", False, "codex 없음(brew install codex)"))
    try:
        runner = codex_runner()
        supported = runner.is_file() and "--bypass-hook-trust" in runner.read_text(encoding="utf-8")
        detail = str(runner) if supported else f"{runner} — --bypass-hook-trust 미지원(/plugin update orca-team@setup-with-orca)"
        checks.append(Check("Codex 래퍼 --bypass-hook-trust", supported, detail))
    except OrchError as exc:
        checks.append(Check("Codex 래퍼 --bypass-hook-trust", False, str(exc)))
    return checks


def scaffold(root: Path, description: str) -> dict:
    if not description.strip():
        raise OrchError("프로젝트 설명이 비었다", 2)
    created, skipped = [], []
    for src, dst in SCAFFOLD_FILES:
        target = root / dst
        if target.exists():
            skipped.append(dst)
            continue
        target.parent.mkdir(parents=True, exist_ok=True)
        shutil.copyfile(TEMPLATES / src, target)
        created.append(dst)
    (root / ".orchestration/bin/orch").chmod(0o755)
    project_md = root / ".orchestration/project.md"
    if project_md.exists():
        skipped.append(".orchestration/project.md")
    else:
        project_md.write_text(f"# 프로젝트 설명\n\n{description.strip()}\n", encoding="utf-8")
        created.append(".orchestration/project.md")
    keep = root / ".orchestration/tasks/.gitkeep"
    keep.parent.mkdir(parents=True, exist_ok=True)
    keep.touch()
    for src, dst in APPEND_FILES:
        target = root / dst
        current = target.read_text(encoding="utf-8") if target.exists() else ""
        if MARK in current:
            skipped.append(dst)
            continue
        section = (TEMPLATES / src).read_text(encoding="utf-8")
        target.write_text((current.rstrip() + "\n\n" if current.strip() else "") + section, encoding="utf-8")
        created.append(dst)
    gitignore = root / ".gitignore"
    text = gitignore.read_text(encoding="utf-8") if gitignore.exists() else ""
    if GITIGNORE_LINE not in text.splitlines():
        gitignore.write_text(text + ("\n" if text and not text.endswith("\n") else "") + GITIGNORE_LINE + "\n",
                             encoding="utf-8")
        created.append(".gitignore")
    p = Project(root)
    p.ensure_state()
    p.setup_mode.touch()
    return {"root": str(root), "created": created, "skipped": skipped}


def setup_done(p: Project) -> dict:
    p.setup_mode.unlink(missing_ok=True)
    return {"setup_mode": False}
```

```python
"""메인 ⇄ 코디네이터 소통.

코디네이터 → 메인: outbox.jsonl(파일). 메인은 Run 에 묶이지 않으므로 Orca 알림이 메인 입력란에 들어오지 않는다.
메인 → 코디네이터: 코디네이터 Run 메일함(orca orchestration send --to run:<id>).
"""
from __future__ import annotations

import json
import os
import time

from . import orca
from .paths import OrchError, Project
from .util import load_run, now, pid_alive

TYPES = ("progress", "question", "done")
WAIT_TYPES = "worker_done,escalation,question,status"


def read_outbox(p: Project) -> list[dict]:
    if not p.outbox.exists():
        return []
    return [json.loads(line) for line in p.outbox.read_text(encoding="utf-8").splitlines() if line.strip()]


def cursor(p: Project) -> int:
    try:
        return int(p.outbox_cursor.read_text(encoding="utf-8").strip() or 0)
    except (OSError, ValueError):
        return 0


def unread(p: Project) -> list[dict]:
    return read_outbox(p)[cursor(p):]


def notify(p: Project, kind: str, body: str) -> dict:
    if kind not in TYPES:
        raise OrchError(f"--type 은 {'|'.join(TYPES)} 중 하나다", 2)
    if not body.strip():
        raise OrchError("메시지 본문이 비었다", 2)
    p.ensure_state()
    entry = {"id": f"out-{len(read_outbox(p)) + 1:04d}", "type": kind, "body": body.strip(), "at": now()}
    with p.outbox.open("a", encoding="utf-8") as fh:
        fh.write(json.dumps(entry, ensure_ascii=False) + "\n")
    return entry


def watch(p: Project, poll: float = 2.0, timeout: float | None = None) -> list[dict]:
    """새 outbox 줄이 생기면 돌려주고 끝난다. Orca 를 호출하지 않는다."""
    p.ensure_state()
    if pid_alive(p.watch_pid):
        raise OrchError(f"watch 가 이미 실행 중이다(pid {p.watch_pid.read_text(encoding='utf-8').strip()})", 3)
    p.watch_pid.write_text(f"{os.getpid()}\n", encoding="utf-8")
    deadline = None if timeout is None else time.monotonic() + timeout
    try:
        while True:
            lines, seen = read_outbox(p), cursor(p)
            if len(lines) > seen:
                p.outbox_cursor.write_text(str(len(lines)), encoding="utf-8")
                return lines[seen:]
            if deadline is not None and time.monotonic() >= deadline:
                return []
            time.sleep(poll)
    finally:
        try:
            if p.watch_pid.read_text(encoding="utf-8").split()[:1] == [str(os.getpid())]:
                p.watch_pid.unlink()
        except OSError:
            pass


def tell(p: Project, body: str, reply_to: str | None = None) -> dict:
    run_id = load_run(p).get("run_id")
    if not run_id:
        raise OrchError("코디네이터가 아직 Run 을 만들지 않았다. /orca-team:up 으로 확인한다", 1)
    if not body.strip():
        raise OrchError("메시지 본문이 비었다", 2)
    subject = f"[main] reply {reply_to}" if reply_to else f"[main] {body.strip().splitlines()[0][:60]}"
    _, data = orca.call(["orchestration", "send", "--to", f"run:{run_id}", "--type", "status",
                         "--subject", subject, "--body", body.strip()])
    return {"sent": True, "subject": subject, "receipt": data.get("result")}


def wait(p: Project, ack: str | None, timeout_ms: int) -> dict:
    """코디네이터 메일함 대기. 한 번에 하나만 돈다. 호출 전 require_coordinator 를 확인한다."""
    p.ensure_state()
    if pid_alive(p.wait_pid):
        raise OrchError(f"wait 가 이미 실행 중이다(pid {p.wait_pid.read_text(encoding='utf-8').strip()})", 3)
    p.wait_pid.write_text(f"{os.getpid()}\n", encoding="utf-8")
    try:
        args = ["orchestration", "check"]
        if ack:
            args += ["--ack", ack]
        args += ["--wait", "--types", WAIT_TYPES, "--timeout-ms", str(timeout_ms)]
        _, data = orca.call(args)
        return data
    finally:
        p.wait_pid.unlink(missing_ok=True)
```

```python
    role: str
    title: str
    front: dict
    body: str

def parse_task(path: Path) -> TaskDoc:
    match = FRONT_RE.match(path.read_text(encoding="utf-8"))
    if not match:
        raise OrchError(f"{path}: front matter(---) 가 없다", 2)
    front = {}
    for line in match.group(1).splitlines():
        if ":" in line:
            key, value = line.split(":", 1)
            front[key.strip()] = value.strip()
    body = match.group(2)
    sections, current = {}, None
    for line in body.splitlines():
        if line.startswith("## "):
            current = line[3:].strip()
            sections[current] = []
        elif current:
            sections[current].append(line)
    return TaskDoc(front.get("id", ""), front.get("role", ""), front.get("title", ""), front, body.strip(),
                   {k: "\n".join(v).strip() for k, v in sections.items()})


def validate(doc: TaskDoc, cfg: Config, expected_id: str) -> None:
    problems = []
    if doc.id != expected_id:
        problems.append(f"front matter id={doc.id or '없음'}")
    if doc.role not in cfg.roles:
        problems.append(f"role={doc.role or '없음'}")
    if not doc.title:
        problems.append("title 없음")
    for name in REQUIRED_SECTIONS:
        lines = [line.strip() for line in doc.sections.get(name, "").splitlines() if line.strip()]
        if not lines or all(PLACEHOLDER_RE.match(line) for line in lines):
            problems.append(f"## {name} 비었음")
    if problems:
        raise OrchError(f"{expected_id} spec 불완전: {', '.join(problems)}", 2)


def load_doc(p: Project, cfg: Config, task_id: str) -> TaskDoc:

        raise OrchError(f"태스크 ID 형식이 아니다: {task_id}", 2)
    path = task_path(p, task_id)
    if not path.is_file():
        raise OrchError(f"태스크 spec 없음: {path}", 2)
    doc = parse_task(path)
    validate(doc, cfg, task_id)
    return doc

def check_lock(p: Project, task_id: str, owns: list[str]) -> None:
    conflicts = []

def launch(p: Project, cfg: Config, doc: TaskDoc, st: dict, stage: str, rnd: int, owns: list[str],
           note: str | None, terminal: str | None, overrides: dict | None) -> dict:
    spec = compose_spec(p, cfg, doc, stage, rnd, owns, note)
    cmd = ["orchestration", "worker-start", "--spec", spec,
           "--task-title", f"{doc.id} {stage} r{rnd} [{doc.role}] {doc.title}", "--worktree", "current"]
    if terminal:
        cmd += ["--terminal", terminal]
    else:
        pref = cfg.claude(doc.role, {**doc.front, **(overrides or {})})
        cmd += ["--agent", "claude", "--model", pref.model, "--effort", pref.effort]
    code, receipt = orca.call(cmd, check=False)
    log_dir = p.task_state_dir / doc.id
    log_dir.mkdir(parents=True, exist_ok=True)
    stamp = datetime.now().strftime("%Y%m%d-%H%M%S")
    (log_dir / f"{stage}-r{rnd}-{stamp}.spec.md").write_text(spec, encoding="utf-8")
    receipt_path = log_dir / f"{stage}-r{rnd}-{stamp}.receipt.json"
    write_json(receipt_path, receipt)
    ok = code == 0 and bool(receipt.get("ok"))
    entry = {"stage": stage, "round": rnd, "at": now(), "ok": ok,
             "task_id": orca.find_key(receipt, ("taskId",)), "dispatch_id": orca.find_key(receipt, ("dispatchId",)),
             "terminal_reused": terminal,
             "launch": ((receipt.get("result") or {}).get("launch") or {}).get("effective"),
             "receipt": str(receipt_path.relative_to(p.root))}
    st["history"].append(entry)
    st.update(stage=stage, round=rnd, owns=owns)
    if ok:
        st.update(status="working", task_id=entry["task_id"], dispatch_id=entry["dispatch_id"])
    else:
        st["status"] = "launch_failed"
    save_state(p, st)
    if not ok:
        raise OrchError("worker-start 실패. 같은 명령을 그냥 다시 돌리지 않는다. 영수증의 failedStage·residualResources 를 보고 "
                        f"Orca recovery 참조(orca skills get orchestration --reference references/recovery-and-cleanup.md)를 "
                        f"따른 뒤 --retry 로 다시 한다: {receipt_path}")
    return entry

    doc = load_doc(p, cfg, task_id)
    st = load_state(p, task_id)
    if st is not None and not (retry and st.get("status") == "launch_failed" and st.get("stage") == "work"):
        raise OrchError(f"{task_id} 는 이미 시작됐다(status={st.get('status')}). 수정 라운드는 orch fix", 2)
    if st is None and retry:
        raise OrchError(f"{task_id}: --retry 할 실패 기록이 없다", 2)
    owns = owns_of(doc, cfg)
    check_lock(p, task_id, owns)
    if st is None:
        st = {"id": task_id, "role": doc.role, "title": doc.title, "status": "new", "stage": "work", "round": 1,
              "base": git(p.root, "rev-parse", "HEAD").strip(), "owns": owns, "task_id": None, "dispatch_id": None,
              "history": [], "verdicts": {}}
    return launch(p, cfg, doc, st, "work", 1, owns, None, None, overrides)


def fix(p: Project, cfg: Config, task_id: str, note: str | None = None, retry: bool = False,
        overrides: dict | None = None) -> dict:
    require_coordinator(p)
    doc = load_doc(p, cfg, task_id)
    st = must_state(p, task_id)
    if retry:
        if not (st.get("status") == "launch_failed" and st.get("stage") == "fix"):
            raise OrchError(f"{task_id}: --retry 는 fix 실행이 실패한 뒤에만 쓴다(status={st.get('status')})", 2)
        rnd = st["round"]
    else:
        if st.get("status") not in ("changes", "working"):
            raise OrchError(f"{task_id}: fix 는 changes 또는 working(워커 실패 보고) 상태에서만 한다"
                            f"(status={st.get('status')})", 2)
        if st["round"] >= cfg.max_rounds:
            raise OrchError(f"{task_id}: 최대 {cfg.max_rounds} 라운드에 도달했다. "
                            "orch notify --type question 으로 메인에 판단을 요청한다", 1)
        rnd = st["round"] + 1
    terminal = None
    if st.get("dispatch_id"):
        handle, verdict = orca.worker_terminal(st["dispatch_id"])
        terminal = handle if verdict == "live" else None
    return launch(p, cfg, doc, st, "fix", rnd, owns_of(doc, cfg), note, terminal, overrides)


def accept(p: Project, cfg: Config, task_id: str) -> dict:
    require_coordinator(p)
    st = must_state(p, task_id)
    if st.get("status") != "approved":
        raise OrchError(f"{task_id}: APPROVE 된 태스크만 accept 한다(status={st.get('status')})", 2)
    code, data = orca.call(["orchestration", "worker-release", "--dispatch", str(st.get("dispatch_id"))], check=False)
    released = code == 0 and bool(data.get("ok"))
    st.update(status="done", released=released, done_at=now())
    save_state(p, st)
    msg = notify(p, "progress", f"{task_id} [{cfg.title(st['role'])}] {st['title']} — APPROVE (r{st['round']})")
    result = {"id": task_id, "status": "done", "released": released, "notified": msg["id"]}
    if not released:
        result["release_error"] = data
    return result


def which(p: Project, ref: str) -> dict:
    for st in all_states(p):
        refs = {st.get("task_id"), st.get("dispatch_id")}
        for entry in st.get("history", []):
            refs.update((entry.get("task_id"), entry.get("dispatch_id")))
        if ref in refs:
            return {k: st.get(k) for k in ("id", "role", "title", "status", "round")}
    raise OrchError(f"{ref} 에 해당하는 태스크가 없다", 1)
```

```python
    """코디네이터가 살아 있으면 그대로 두고, 없으면 고정 플래그로 띄운다(메인이 호출)."""

        result = {"status": "running", "handle": run["coordinator_handle"]}
    else:
        launch = cfg.coordinator()
        code, receipt = orca.call(["agent", "launch", "--agent", "claude", "--surface", "terminal",
                                   "--worktree", f"path:{p.root}", "--model", launch.model,

    path = p.orch / "project.md"
    text = path.read_text(encoding="utf-8") if path.exists() else ""
    lines = [line.strip() for line in text.splitlines() if line.strip() and not line.startswith("#")]
    return (lines[0] if lines else p.root.name)[:120]


def bind(p: Project) -> dict:
    """코디네이터 터미널을 Run 에 묶는다. 처음이면 만들고, 있으면 다시 붙는다."""
    require_coordinator(p)
    run = load_run(p)
    if run.get("run_id"):
        orca.call(["orchestration", "run-use", "--id", run["run_id"]])
        return {"status": "rebound", "run_id": run["run_id"]}
    _, data = orca.call(["orchestration", "run-create", "--objective", project_objective(p)])
    result = data.get("result") or {}
    run_id = result.get("runId") or (result.get("run") or {}).get("id") or orca.find_key(result, ("runId",))
    if not run_id:
        raise OrchError(f"run-create 응답에서 Run ID 를 찾지 못했다: {data}")
    run["run_id"] = run_id
    save_run(p, run)
    return {"status": "created", "run_id": run_id}


def status(p: Project) -> dict:
    run = load_run(p)
    try:
        alive = orca.terminal_alive(run.get("coordinator_handle"))
    except OrchError:
        alive = None
    return {"run_id": run.get("run_id"),
            "coordinator": {"handle": run.get("coordinator_handle"), "alive": alive},
            "watch_alive": pid_alive(p.watch_pid), "unread_outbox": len(unread(p)),
            "setup_mode": p.setup_mode.exists(),
            "tasks": [{k: st.get(k) for k in ("id", "role", "title", "status", "round")} for st in all_states(p)]}
```

```python
"""리뷰: 커밋·소유 경로 사전 검사 → Codex 래퍼로 Codex 리뷰 → 판정 기록·커밋."""
from __future__ import annotations

import hashlib
import os
import re
import subprocess
from datetime import datetime
from pathlib import Path

from . import orca
from .config import Config
from .globs import matches_any
from .paths import TEMPLATES, OrchError, Project, codex_runner
from .tasks import ACTIVE, TaskDoc, all_states, load_doc, must_state, owns_of, save_state
from .util import git, git_commit_paths, now, read_json, render, require_coordinator

VERDICT_RE = re.compile(r"^VERDICT:\s*(APPROVE|REQUEST_CHANGES)\s*$", re.M)


def task_commits(root: Path, task_id: str, base: str) -> list[tuple[str, str]]:
    """base 이후 `[T-xxx]` 작업 커밋. spec·review 커밋은 뺀다."""
    skip = (f"[{task_id}] review", f"[{task_id}] spec")
    commits = []
    for line in git(root, "log", "--reverse", "--format=%H%x09%s", f"{base}..HEAD").splitlines():
        sha, _, subject = line.partition("\t")
        if subject.startswith(f"[{task_id}]") and not subject.startswith(skip):
            commits.append((sha, subject))
    return commits


def changed_files(root: Path, shas: list[str]) -> list[str]:
    files = set()
    for sha in shas:
        out = git(root, "diff-tree", "--no-commit-id", "--name-only", "-r", "--root", sha)
        files.update(line for line in out.splitlines() if line)
    return sorted(files)


def violations(files: list[str], owns: list[str], task_id: str) -> list[str]:
    allowed = [*owns, f"docs/tasks/{task_id}/**"]
    return [f for f in files if not matches_any(f, allowed)]


def snapshot(root: Path, exclude: list[str]) -> dict[str, str]:
    """작업 트리 변경 파일의 내용 해시. exclude(동시에 다른 주체가 쓰는 경로)는 뺀다."""
    entries = git(root, "status", "--porcelain=v1", "-z", "--untracked-files=all").split("\0")
    result, i = {}, 0
    while i < len(entries):
        entry = entries[i]
        i += 1
        if len(entry) < 4:
            continue
        status, path = entry[:2], entry[3:]
        if status[0] in "RC":
            i += 1
        if matches_any(path, exclude):
            continue
        target = root / path
        result[path] = hashlib.sha1(target.read_bytes()).hexdigest() if target.is_file() else "-"
    return result


def read_verdict(path: Path) -> str | None:
    if not path.is_file():
        return None
    found = VERDICT_RE.findall(path.read_text(encoding="utf-8"))
    return found[-1] if found else None


def run_dir_for(p: Project, task_id: str, rnd: int, attempt: int) -> Path:
    base = Path(os.environ.get("XDG_CACHE_HOME") or Path.home() / ".cache")
    stamp = datetime.now().strftime("%Y%m%d-%H%M%S")
    path = base / "orca-team" / "runs" / p.root.name / f"{task_id}-r{rnd}-{stamp}-a{attempt}"
    path.mkdir(parents=True, exist_ok=True)
    return path


def compose_prompt(p: Project, cfg: Config, doc: TaskDoc, rnd: int, review_rel: str,
                   commits: list[tuple[str, str]], files: list[str]) -> str:
    prior = [f"docs/reviews/{doc.id}/r{n}.md" for n in range(1, rnd)
             if (p.root / f"docs/reviews/{doc.id}/r{n}.md").is_file()]
    return render((TEMPLATES / "review-prompt.md").read_text(encoding="utf-8"), {
        "task_id": doc.id, "round": rnd, "role": doc.role, "role_title": cfg.title(doc.role), "title": doc.title,
        "review_path": review_rel, "prior_reviews": ", ".join(prior) or "없음",
        "commits": "\n".join(f"- {sha[:10]} {subject}" for sha, subject in commits),
        "files": "\n".join(f"- {f}" for f in files)})


def review_exclusions(p: Project, task_id: str) -> list[str]:
    exclude = [".orchestration/**", "docs/reviews/**"]
    for st in all_states(p):
        if st["id"] != task_id and st.get("status") in ACTIVE:
            exclude += [*st.get("owns", []), f"docs/tasks/{st['id']}/**"]
    return exclude


def codex_review(p: Project, cfg: Config, doc: TaskDoc, rnd: int, review_rel: str, prompt: str) -> str:
    launch = cfg.codex(doc.role, doc.front)
    runner = codex_runner()
    review_file = p.root / review_rel
    exclude = review_exclusions(p, doc.id)
    last_dir = None
    for attempt in (1, 2):
        review_file.unlink(missing_ok=True)
        before = snapshot(p.root, exclude)
        run_dir = last_dir = run_dir_for(p, doc.id, rnd, attempt)
        (run_dir / "prompt.txt").write_text(prompt, encoding="utf-8")
        proc = subprocess.run([str(runner), "--profile", "run", "--cwd", str(p.root),
                               "--prompt-file", str(run_dir / "prompt.txt"), "--run-dir", str(run_dir),
                               "--model", launch.model, "--effort", launch.effort, "--bypass-hook-trust"],
                              capture_output=True, text=True)
        if proc.returncode in (2, 12):
            raise OrchError(f"Codex 래퍼 실행 불가(exit {proc.returncode}): {(proc.stdout + proc.stderr)[-600:]}",
                            12 if proc.returncode == 12 else 1)
        after = snapshot(p.root, exclude)
        touched = sorted(path for path in set(before) | set(after) if before.get(path) != after.get(path))
        if touched:
            raise OrchError(f"Codex 가 리뷰 중 파일을 바꿨다: {', '.join(touched)}. 판정 무효. 변경은 그대로 두고 "
                            f"orch notify --type question 으로 메인에 올린다. run-dir: {run_dir}")
        status = read_json(run_dir / "status.json", {})
        if status.get("terminal_event") == "turn.completed":
            verdict = read_verdict(review_file)
            if verdict:
                return verdict
    raise OrchError(f"Codex 리뷰가 2회 모두 판정을 내지 못했다. run-dir: {last_dir}. "
                    "orch notify --type question 으로 메인에 올린다")


def auto_review(p: Project, review_rel: str, task_id: str, rnd: int, reason: str) -> str:
    path = p.root / review_rel
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(f"# {task_id} r{rnd} 리뷰 (orch 사전 검사)\n\n{reason}\n\nVERDICT: REQUEST_CHANGES\n",
                    encoding="utf-8")
    return "REQUEST_CHANGES"


def review(p: Project, cfg: Config, task_id: str) -> dict:
    require_coordinator(p)
    doc = load_doc(p, cfg, task_id)
    st = must_state(p, task_id)
    if st.get("status") != "working":
        raise OrchError(f"{task_id}: 리뷰는 워커가 끝난 working 상태에서만 한다(status={st.get('status')})", 2)
    rnd, owns = st["round"], owns_of(doc, cfg)
    review_rel = f"docs/reviews/{task_id}/r{rnd}.md"
    if st.get("dispatch_id"):
        orca.call(["orchestration", "worker-retain", "--dispatch", st["dispatch_id"]], check=False)
    st["status"] = "reviewing"
    save_state(p, st)
    try:
        commits = task_commits(p.root, task_id, st["base"])
        files = changed_files(p.root, [sha for sha, _ in commits])
        bad = violations(files, owns, task_id)
        if not commits:
            reason = f"`[{task_id}]` 로 시작하는 작업 커밋이 base({st['base'][:10]}) 이후에 없다."
            verdict, source = auto_review(p, review_rel, task_id, rnd, reason), "orch"
        elif bad:
            reason = (f"소유 경로 밖 파일을 커밋했다(허용: {', '.join(owns)}, docs/tasks/{task_id}/**):\n"
                      + "\n".join(f"- {f}" for f in bad))
            verdict, source = auto_review(p, review_rel, task_id, rnd, reason), "orch"
        else:
            prompt = compose_prompt(p, cfg, doc, rnd, review_rel, commits, files)
            verdict, source = codex_review(p, cfg, doc, rnd, review_rel, prompt), "codex"
        git_commit_paths(p.root, [review_rel], f"[{task_id}] review r{rnd}: {verdict}")
    except OrchError:
        st["status"] = "working"
        save_state(p, st)
        raise
    st.setdefault("verdicts", {})[str(rnd)] = verdict
    st["status"] = "approved" if verdict == "APPROVE" else "changes"
    st["history"].append({"stage": "review", "round": rnd, "at": now(), "verdict": verdict, "source": source})
    save_state(p, st)
    return {"id": task_id, "round": rnd, "verdict": verdict, "source": source, "review": review_rel}
```

```python
#!/usr/bin/env python3
"""orca-team 훅. 사용법: orca_team_hook.py <role-mark|guard|session-start|stop>

`.orchestration/config.toml` 이 없는 프로젝트에서는 아무것도 하지 않는다.
훅 오류로 세션이 막히면 안 되므로 예외는 state/hook-errors.log 에 남기고 통과시킨다.
"""
from __future__ import annotations

import json
import os
import re
import sys
import traceback
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parents[1] / "lib"))

from orch.comm import unread  # noqa: E402
from orch.paths import Project  # noqa: E402
from orch.util import load_run, now, pid_alive  # noqa: E402

COORDINATOR_MARK = "[orca-team:coordinator]"
WORKER_MARKS = ("Your task ID is:", "=== TASK ===", "Please carry out this task from my Orca coordinator")
SETUP_PREFIXES = (".claude/", ".orchestration/", "docs/superpowers/")
SETUP_FILES = {"CLAUDE.md", "AGENTS.md", ".gitignore"}
EDIT_TOOLS = {"Edit", "Write", "MultiEdit", "NotebookEdit"}
ORCA_ORCHESTRATION_RE = re.compile(r"(^|[\s;&|(`])orca\s+orchestration\b")


def find_project(payload: dict) -> Project | None:
    start = Path(os.environ.get("CLAUDE_PROJECT_DIR") or payload.get("cwd") or os.getcwd()).resolve()
    for folder in (start, *start.parents):
        if (folder / ".orchestration" / "config.toml").is_file():
            return Project(folder)
    return None


def role_of(p: Project, session_id: str | None) -> str:
    marker = p.sessions / session_id if session_id else None
    if marker is not None and marker.is_file():
        return marker.read_text(encoding="utf-8").strip() or "main"
    return "main"


def role_mark(p: Project, payload: dict):
    session_id = payload.get("session_id")
    if not session_id or (p.sessions / session_id).exists():
        return None
    prompt = payload.get("prompt") or ""
    if prompt.lstrip().startswith(COORDINATOR_MARK):
        role = "coordinator"
    elif any(mark in prompt for mark in WORKER_MARKS):
        role = "worker"
    else:
        role = "main"
    p.ensure_state()
    (p.sessions / session_id).write_text(role + "\n", encoding="utf-8")
    return None


def product_path(p: Project, raw: str) -> str | None:
    """프로젝트 안 산출물 파일이면 상대 경로, 아니면 None."""
    if not raw:
        return None
    path = Path(raw)
    if not path.is_absolute():
        path = p.root / path
    try:
        rel = path.resolve().relative_to(p.root.resolve()).as_posix()
    except ValueError:
        return None
    if rel in SETUP_FILES or rel.startswith(SETUP_PREFIXES):
        return None
    return rel


def deny(reason: str) -> dict:
    return {"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "deny",
                                   "permissionDecisionReason": reason}}


def guard(p: Project, payload: dict):
    role = role_of(p, payload.get("session_id"))
    tool = payload.get("tool_name") or ""
    tool_input = payload.get("tool_input") or {}
    if tool == "AskUserQuestion" and role == "coordinator":
        return deny("코디네이터는 사용자에게 직접 묻지 않는다. "
                    '`.orchestration/bin/orch notify --type question "<질문·선택지·추천>"` 으로 메인에 올린다.')
    if tool == "AskUserQuestion" and role == "worker":
        return deny("워커는 사용자에게 직접 묻지 않는다. 프리앰블의 ask 명령으로 코디네이터에게 묻는다.")
    if tool in EDIT_TOOLS and role in ("main", "coordinator"):
        rel = product_path(p, tool_input.get("file_path") or tool_input.get("notebook_path") or "")
        if rel and not (role == "main" and p.setup_mode.exists()):
            if role == "main":
                return deny(f"메인은 산출물({rel})을 직접 수정하지 않는다. "
                            '`.orchestration/bin/orch tell "<요청>"` 으로 코디네이터에게 넘긴다.')
            return deny(f"코디네이터는 산출물({rel})을 직접 수정하지 않는다. `orch task new` 로 태스크를 만들어 워커에게 맡긴다.")
    if tool == "Bash" and role == "main" and ORCA_ORCHESTRATION_RE.search(tool_input.get("command") or ""):
        return deny("메인은 `orca orchestration` 을 직접 호출하지 않는다. 메인이 Run 에 묶이면 Orca 알림이 사용자 입력란에 "
                    "들어온다. `.orchestration/bin/orch tell` 을 쓴다.")
    return None


def session_start(p: Project, payload: dict):
    if role_of(p, payload.get("session_id")) != "main":
        return None
    lines = ["orca-team 프로젝트다. 이 세션의 첫 프롬프트가 `[orca-team:coordinator]` 나 Orca 디스패치 프리앰블이 아니면 너는 메인이다.",
             '- 메인은 사용자와 대화만 한다. 산출물 작업은 `.orchestration/bin/orch tell "<요청>"` 으로 코디네이터에게 넘긴다.',
             "- 먼저 `/orca-team:up` 으로 코디네이터와 메시지 watcher 를 확인한다."]
    pending = len(unread(p))
    if pending:
        lines.append(f"- 아직 전하지 않은 코디네이터 메시지가 {pending}건 있다. watcher 를 띄우면 바로 받는다.")
    return {"hookSpecificOutput": {"hookEventName": "SessionStart", "additionalContext": "\n".join(lines)}}


def stop(p: Project, payload: dict):
    if payload.get("stop_hook_active") or role_of(p, payload.get("session_id")) != "main":
        return None
    if p.setup_mode.exists() or not load_run(p).get("coordinator_handle") or pid_alive(p.watch_pid):
        return None
    return {"decision": "block",
            "reason": "orca-team: 코디네이터 메시지 watcher 가 꺼져 있다. Bash `run_in_background: true` 로 "
                      "`.orchestration/bin/orch watch` 를 띄우고 턴을 끝낸다. 이미 받은 메시지가 있으면 사용자에게 먼저 전한다."}


HANDLERS = {"role-mark": role_mark, "guard": guard, "session-start": session_start, "stop": stop}


def main() -> int:
    if len(sys.argv) != 2 or sys.argv[1] not in HANDLERS:
        return 0
    try:
        payload = json.loads(sys.stdin.read() or "{}")
    except json.JSONDecodeError:
        return 0
    p = find_project(payload)
    if p is None:
        return 0
    try:
        out = HANDLERS[sys.argv[1]](p, payload)
    except Exception:  # noqa: BLE001  훅은 세션을 막지 않는다
        try:
            p.ensure_state()
            with (p.state / "hook-errors.log").open("a", encoding="utf-8") as fh:
                fh.write(f"{now()} {sys.argv[1]}\n{traceback.format_exc()}\n")
        except OSError:
            pass
        return 0
    if out:
        print(json.dumps(out, ensure_ascii=False))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

````markdown
# /orca-team:init

이 세션은 **메인**이다. 단계 순서를 바꾸지 않는다. 명령은 적힌 그대로 실행한다.

아래 `ORCH` 는 `python3 "${CLAUDE_PLUGIN_ROOT}/bin/orch"` 다. 3단계 이후에는 프로젝트 shim `.orchestration/bin/orch` 를 쓴다.

## 1. 설명 확인
인자: `$ARGUMENTS`

비어 있으면 "어떤 프로젝트인지 한두 문장으로 알려 달라"고 묻고 멈춘다.

## 2. 점검
`ORCH doctor` 를 실행한다.
- `warn git 저장소` 면 `git init` 후 `git commit --allow-empty -m "chore: init"` 을 실행한다.
- `FAIL` 이 있으면 출력 표와 각 detail 의 고칠 방법을 보여주고 멈춘다.
- `FAIL Codex 래퍼 --bypass-hook-trust` 면 `/plugin marketplace update setup-with-orca` 다음 `/plugin update orca-team@setup-with-orca` 를 안내한다.

## 3. 스캐폴드
설명 원문을 스크래치 파일에 쓰고 `ORCH scaffold --description-file <그 파일>` 을 실행한다. 출력의 created·skipped 를 기억한다.

## 4. 설치 목록 제안 — 판단이 들어가는 유일한 단계
프로젝트 설명과 저장소 상태를 보고 표 하나를 만든다.

| 구분 | 이름 | 이유 | 범위 | 명령·변경 |
|---|---|---|---|---|

- 구분은 다섯 가지다: 스킬, 플러그인, 프로그램, 직무 owns, 추가 직무.
- 이미 설치된 것은 넣지 않는다. `claude plugin list`, `which <도구>`, `brew list` 로 확인한다.
- 직무 owns: 프로젝트 구조에 맞춘 `.orchestration/config.toml` 의 `[roles.*].owns` 값이다. 예: Next.js 면 developer `["src/**", "app/**", "package.json"]`.
- 추가 직무: 기본 4개(planner·designer·developer·tester)로 부족할 때만 넣는다. `.orchestration/roles/<role>.md`(기본 직무 파일과 같은 절 구성)와 config 항목을 같이 만든다.
- 텔레그램 등 채널은 넣지 않는다.
- AskUserQuestion 으로 한 번에 승인받는다. 옵션: "전부 승인(Recommended)", "설치 없이 진행". 일부 제외는 Other 로 받는다.
- 승인된 항목을 설치·적용한다. 실패해도 멈추지 않고 표에 결과(성공/실패)를 남긴다.

## 5. 코디네이터 기동
1. `.orchestration/bin/orch up --wait-run 180` 을 실행한다.
2. Bash `run_in_background: true` 로 `.orchestration/bin/orch watch` 를 띄운다.
   - 이후 watch 가 끝날 때마다(메시지 도착) CLAUDE.md 의 "메인 규칙" 대로 처리하고 다시 띄운다.

## 6. 마무리
1. `.orchestration/bin/orch setup-done` 을 실행한다.
2. 세팅 파일을 커밋한다: `git add CLAUDE.md AGENTS.md .gitignore .orchestration` 과 4단계에서 바뀐 설정 파일 → `git commit -m "chore: orca-team 세팅"`.
3. 보고한다: 준비 완료, 코디네이터 터미널 handle, 설치 결과 표, "다음 메시지로 첫 업무를 주면 된다".

## 하지 않는 것
- `orca orchestration` 직접 호출. 메인이 Run 에 묶이면 Orca 알림이 사용자 입력란에 들어온다.
- 기획·디자인·코드 작업 시작. 첫 업무는 사용자의 다음 메시지부터다.
````
